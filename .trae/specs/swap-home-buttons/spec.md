# 按钮顺序微调 Spec

## Why
首页操作区与新建文件夹弹窗的按钮顺序与常见交互习惯不一致（主操作应在前/更靠视觉起点），需要只调整 DOM 顺序。

## What Changes
- 首页「我的数据集」标题右侧操作区：由【+ 新建文件夹】→【导入数据】调整为【导入数据】→【+ 新建文件夹】。
- 新建/重命名文件夹弹窗底部：由【取消】→【创建/保存】调整为【创建/保存】→【取消】。
- 仅交换元素顺序，按钮的 `className`、`onClick`、`disabled`、文案、图标与容器布局类（`flex items-center gap-*`、`flex justify-end gap-3`）全部保持不变。

## Impact
- Affected specs: 首页操作区布局、文件夹弹窗底部操作区布局
- Affected code: `src/pages/HomePage.tsx`

## ADDED Requirements
### Requirement: 首页操作区按钮顺序
系统 SHALL 在数据集区域右上角按「导入数据」在左、「+ 新建文件夹」在右的顺序渲染。

#### Scenario: 首页查看操作区
- **WHEN** 打开首页
- **THEN** 操作区从左到右依次为「导 入 数 据」渐变按钮、`+ 新建文件夹` 描边按钮
- **THEN** 两个按钮的点击行为、禁用态与样式与原实现一致

### Requirement: 文件夹弹窗按钮顺序
系统 SHALL 在新建/重命名文件夹弹窗底部按「创建/保存」在左、「取消」在右的顺序渲染。

#### Scenario: 新建文件夹
- **WHEN** 点击「+ 新建文件夹」打开弹窗
- **THEN** 底部从左到右为「创建」（名称为空时禁用）、「取消」
- **THEN** 点击「创建」仍调用 `handleConfirmFolder`，点击「取消」仍关闭弹窗

#### Scenario: 重命名文件夹
- **WHEN** 以重命名模式打开弹窗
- **THEN** 底部左侧按钮文案为「保存」，右侧为「取消」，交互与改动前一致

## MODIFIED Requirements
### Requirement: 文件夹弹窗删除确认
删除文件夹确认弹窗（L~683 起）不在本次调整范围内，保持【取消】在左、【删除】在右。

## Non-Goals
- 不修改任何按钮样式、颜色、圆角、字号、间距类名。
- 不修改其他弹窗（删除确认、重命名入口等）的按钮顺序。
- 不新增/删除按钮或事件处理。
- 不执行任何 git commit / push。
