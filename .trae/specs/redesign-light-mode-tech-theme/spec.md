# 白天模式科技感配色重设计 Spec

## Why
当前白天模式仍存在"曝光感"过强的问题：背景接近纯白、文字对比刺眼、缺乏科技感。用户希望白天模式呈现"白天的赛博朋克"风格——干净、冷冽、现代，使用冷灰调而非暖白调，同时保留霓虹蓝和暗紫强调色。

## What Changes
- 更新 `src/index.css` 浅色模式覆盖规则，使用全新冷灰调科技配色：
  - 页面主背景：`#F8F9FA` → `#F0F4F8`（冷灰蓝）
  - 卡片/面板：`#FFFFFF`（纯白，保持）
  - 次级面板/表格交替行：`#F0F0F4` → `#F7FAFC`（极浅灰蓝）
  - 主标题文字：`#1A1A1E` → `#1A1A2E`（深灰蓝）
  - 正文文字：`#374151` → `#2D3748`（深灰）
  - 辅助文字：`#6B7280` → `#718096`（中灰）
  - 边框/分割线：`#E5E7EB` → `#DCE4EC`（浅灰蓝）
  - 强调色保持 `#6BC5E8` 和 `#7B4B9E` 不变
- 补全缺失的覆盖规则：
  - `border-white/10` → `#DCE4EC`（MobileMenu、Sidebar 等缺失覆盖）
  - `bg-gray-900` 在非代码编辑器场景的覆盖
- 添加主题切换平滑过渡（`transition` on body）
- PowerBIPage 背景色同步更新为冷灰调

## Impact
- Affected code: `src/index.css`（更新浅色模式覆盖区块）
- 不变：黑夜模式所有样式
- 不变：组件 TSX 文件（仅通过 CSS 覆盖实现，不改动组件代码）

## MODIFIED Requirements
### Requirement: 白天模式配色方案
白天模式 SHALL 使用冷灰调科技配色，呈现干净、冷冽、现代的视觉风格。所有深色模式的硬编码颜色类在白天模式下 SHALL 被覆盖为对应的冷灰调颜色。

#### Scenario: 页面背景
- **WHEN** 处于白天模式
- **THEN** 页面主背景为 `#F0F4F8`（冷灰蓝），卡片/面板为 `#FFFFFF`（纯白），次级面板为 `#F7FAFC`

#### Scenario: 文字可读性
- **WHEN** 处于白天模式
- **THEN** 主标题文字为 `#1A1A2E`，正文为 `#2D3748`，辅助文字为 `#718096`，在浅色背景上清晰可读且不刺眼

#### Scenario: 边框与分割线
- **WHEN** 处于白天模式
- **THEN** 所有边框/分割线为 `#DCE4EC`（浅灰蓝），包括之前缺失的 `border-white/10`

#### Scenario: 表格样式
- **WHEN** 处于白天模式
- **THEN** 表头保留暗紫 `#7B4B9E` 科技感样式，交替行为 `#FFFFFF` 和 `#F7FAFC`

#### Scenario: 强调色保持
- **WHEN** 处于白天模式
- **THEN** 霓虹蓝 `#6BC5E8` 和暗紫 `#7B4B9E` 作为强调色，用法与黑夜模式一致

#### Scenario: 平滑过渡
- **WHEN** 切换主题
- **THEN** 背景色、文字色、边框色有 0.3s 平滑过渡动画

#### Scenario: 黑夜模式不受影响
- **WHEN** 处于黑夜模式
- **THEN** 所有样式保持原有深色科技风不变
